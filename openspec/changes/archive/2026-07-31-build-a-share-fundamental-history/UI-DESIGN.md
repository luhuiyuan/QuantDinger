# A 股基本面数据质量 — UI 设计方案

## 位置与权限

- 位置：`设置 / 市场数据 / A 股基本面数据质量`，与现有 `MarketHistoryOperations` 同级或连续区块。
- 仅管理员可见；非管理员显示权限说明，不渲染数据或操作按钮。
- 沿用 Ant Design Vue、当前浅色/深色主题、现有主色；不额外引入字体、图标库或装饰性图表。

## 股票详情页只读浏览

在 `/cn-stocks/:symbol` 的行情摘要下、K 线图前新增“基本面”区块，供所有能查看 A 股详情的用户阅读；它不是管理员运维入口。

```
[ 基本面                                      年报 · 已核验 ]
  最新公告：2026-04-17 · 2025 年报 · 巨潮 / 东方财富

[五年平均ROE] [五年累计FCF] [利息覆盖] [五年平均毛利率]
[五年平均OCF/归母净利] [五年平均净利率] [五年股本变化]

年度历史（最近 5 年）                         查看全部历史
| 报告期 | 公告日 | 营收 | 归母净利 | OCF | FCF | ROE | 状态 |
```

- 指标卡只显示已版本化的标准指标、公式版本和“已核验/待核验/数据不足”状态；不会把数据商当前快照伪装成历史事实。
- “查看全部历史”打开 Drawer，按年度展示所有可得报表及来源版本；原始字段默认折叠。
- 普通用户只看到来源名称、公告日期和公开公告链接；管理员额外看到“查看质量详情”入口，可跳转到对应核验记录。
- 数据尚未回填或缺字段时显示明确空态和原因，不显示零值；详情页不提供回填、重试或修改数据操作。

## 页面信息架构

```
[ A 股基本面数据质量                          刷新 ]
  沪深普通股年度财报 · 东方财富初筛 / 巨潮核验 · 每日 20:30 增量

[回填状态] [年度覆盖] [待核验] [阻断问题] [差异警告] [下次同步]

[概览] [历史回填] [核验与质量] [单股覆盖]
```

### 1. 概览（默认）

- 顶部 6 个紧凑状态卡：回填状态/进度、已覆盖股票数与比例、待核验数、阻断数、>1% 警告数、下一次增量同步时间。
- 任务状态使用文字和 Tag 双重表达：运行中蓝色、成功绿色、暂停/部分完成橙色、失败/阻断红色。
- 下方两列：左侧“最近同步批次”，右侧“需要处理的质量问题”。每项可点击进入对应 Tab 并自动带入筛选条件。
- 不放装饰性图表；覆盖和错误数量对运维决策更直接。

### 2. 历史回填

- 顶部为风险提示：首次回填为串行、可暂停恢复；显示磁盘保护状态，受阻时禁用启动按钮。
- 主操作：`启动回填` 打开确认 Modal，默认范围为“沪深普通股（含退市）/ 全部可得年度历史”；确认框明确“不会保存 PDF、不会自动删除数据”。
- 批次表列：批次 ID、范围、状态、总数、成功/失败/跳过、当前股票、进度、开始/更新时间、最近错误、操作。
- 操作按状态显示：暂停、恢复、仅重试失败、取消、查看详情；危险操作二次确认。

### 3. 核验与质量

- 顶部 Filter：状态（待核验/警告/阻断/已解决）、规则、行业、股票代码、报告期；筛选使用 URL/组件状态保留。
- 主表列：股票、报告期、触发规则、东方财富值、巨潮值、差异、状态、公告日期、最后更新时间、详情。
- 差异列：≤1% 绿色“已核验”；1–5% 橙色“警告”；>5% 红色“阻断”。颜色不是唯一信息，必须有标签和数值。
- 点击行打开右侧 Drawer：展示标准公式、原始字段、两个来源、公告链接、内容哈希、字段映射/公式版本、质量状态时间线。

### 4. 单股覆盖

- 输入规范股票代码，查询后显示年度时间轴/列表：每年报告期、公告日、来源版本、原始字段完整度、标准指标完整度、核验状态。
- 默认折叠原始字段；按需展开，避免把所有财务列压入主表。
- 缺失数据明确列出“缺少何字段/为何数据不足”，不显示为 0 或空白通过。

## 交互与反馈

- 所有后台动作立即返回批次 ID，不等待任务完成；按钮显示 loading 并刷新对应表格。
- 长表使用服务端分页、固定关键列和横向滚动；移动端将状态卡单列、表格降级为卡片摘要 + Drawer。
- 所有可点击卡片、行和操作按钮有 hover/focus 状态；Modal、Drawer 支持键盘焦点与 Escape 关闭。
- API 不可用时沿用现有“后端未启用/版本不支持”空态，不伪造状态。

## 验收标准

- 管理员可在一个页面判断：数据是否在跑、覆盖是否足够、哪些股票不能正式使用、下一步可执行什么。
- 用户无需理解数据表结构，即可从阻断项下钻到规则、字段、来源和公告证据。
- 浅/深色主题、1024px 及以上表格布局、720px 以下单列布局均保持可读和可操作。
